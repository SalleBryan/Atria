# 0002. Book a place in a session

Status: accepted
Source: AD-02 in the Technical Document (ATR-TD-001, section 3)

Constraints: C-01 staffing, C-04 connectivity

## Decision

The general line books a queue ticket in a published session. The patient gets a position and an
arrival window, and the doctor is assigned at check-in by whoever is free.
